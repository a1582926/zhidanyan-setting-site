# 《致：黯淡星》官方设定站

AI 科幻改编版的世界观设定档案站。由主人与同事共同创作维护。

## 目录结构

```
致黯淡星-官方设定站/
├── index.html      # 入口（单页应用，hash 路由）
├── css/style.css   # 样式
├── js/app.js       # 渲染 / 编辑 / 导出逻辑
├── data/data.js    # ★ 全站设定数据（发布后访客看到的就是它）
└── deploy.sh       # 一键部署脚本（需 GitHub 账号）
```

## 日常使用

- **打开**：双击 `index.html`（推荐 Edge/Chrome）
- **浏览**：顶部导航切换板块 —— 星球档案 / 建筑设施 / 天枢系统 / 装备 / 制作进度
- **编辑**：右上角「✎ 编辑」→ 所有内容变成表单，改动即时自动保存到本机浏览器（localStorage）
- **新增**：编辑模式下点「＋ 新增星球/建筑/装备」，删除同理
- **放弃修改**：编辑工具栏「放弃本地修改」恢复为已发布版本

## 发布新版本（流程）

1. 编辑完成后点「导出 data.js（用于发布）」，得到新 `data.js`
2. 用新文件替换 `data/data.js`
3. 把 `index.html` 里 `<script src="data/data.js?v=1">` 的版本号 **+1**（防止访客浏览器缓存旧数据）
4. 执行 `./deploy.sh`（或 `git add -A && git commit -m "更新设定" && git push`）
5. GitHub Pages 自动更新，链接刷新即新版

## 板块与数据字段

| 板块 | 数据键 | 字段 |
|------|--------|------|
| 星球档案 | `planets` | 名称/定位/坐标/直径/平均气温/白日/夜晚/地表构成/大气/磁场/地形地貌/概念图/备注 |
| 建筑设施 | `buildings` | 名称/位置/材料样式/标语与文字/尺寸空间/功能/概念图/备注 |
| 天枢系统 | `tianshu` | 名称/定位/外观/运行原理/能力参数/声线/形态变化/备注 |
| 装备 | `equipment` | 名称/类型/用途/外观款式/技术参数/概念图/备注 |
| 制作进度 | `production` | 项目/状态(done/wip/todo)/说明 |

## 设计说明

- 无任何外部资源依赖（无 CDN/字体/图标库），国内访问无障碍
- 行星概念图未上传时自动生成程序化 SVG 球体（feTurbulence 纹理），后续可替换为 ComfyUI 生成的概念图
- 色彩体系呼应剧本：灰（秩序）→ 金（裂隙/爱）→ 紫（归宿）
